# Inventory evidence comparison implementation

A comparison freezes the exact saved requirement snapshot, catalogue fingerprint,
selected recorded nodes, organization/environment, time question, product and
confirmed mapping fingerprints, source observations and evaluator version. It is
retained in an interop-owned typed journal, separate from exchange documents.
Portfolio owns the deterministic evaluator and curated projection. A narrow
composition port connects journal/source reads to the portfolio workflow.

Sequence (test first): neutral contracts and interval/context evaluator; curated
assertions and projection; retained scoped journal and authorized source leases;
comparison/review application; shared EN/DE user workflow and retention checks.
No aggregate score establishes suitability. Explicit hard contradictions prevent
selection. Unknown boundaries, planned assertions and partial coverage remain
visible. Reopening/exporting retained results never reads a remote source.

Source profiles and grants are operator configuration, bound to repository,
organization, actor and approved selector. No profile means no outbound call.
Credentials are environment references only, never retained with observations.
Reviews require the retained fingerprint, exact demand/product versions and
current authorization; repeat IDs are idempotent only for identical payloads.

Verification: focused Maven RED/GREEN tests, module suites with -am, Maven-owned
browser path where available. Controller owns final reactor/CI verification.
