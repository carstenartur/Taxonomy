# ReqIF 1.2 normative schema set

Specification: https://www.omg.org/spec/ReqIF/1.2

ReqIF 1.2 references the 20110401 ReqIF schema and 20110402 XHTML driver.
The normative XML header value remains `REQ-IF-VERSION=1.0`; it is not the specification publication version.

Retrieved from Eclipse RMF's unchanged standards-schema distribution:
https://github.com/eclipse-rmf/org.eclipse.rmf/tree/b711d21a259d78b93ce76ccaa3a0d73ac446fcd6/org.eclipse.rmf.reqif10.serialization/schema

Source commit: `b711d21a259d78b93ce76ccaa3a0d73ac446fcd6`.
Only CRLF line endings were normalized to LF. See `about.html` for the upstream
OMG/W3C third-party notices and `about_files/W3CLicense.html` for the W3C licence.
Schema resolution uses only this pinned allow-list and never accesses the network.
